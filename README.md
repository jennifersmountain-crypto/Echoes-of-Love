## 🚀 Quick Start (5 minutes)

### 1. Create Supabase Project (Free)

1. Go to [supabase.com](https://supabase.com) and sign up (free)
2. Click **New Project** → Choose your region → Name it "Echoes of Love"
3. Wait for the database to be provisioned (takes ~2 minutes)
4. Go to **Settings → API** and copy:
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### 2. Set Up Database (Copy Paste)

In Supabase dashboard, go to **SQL Editor** and run this query to create all tables:

```sql
-- Echoes of Love - Database Schema

-- Users table
CREATE TABLE public.profiles (
  id UUID REFERENCES auth.users ON DELETE CASCADE,
  display_name TEXT,
  avatar_url TEXT,
  email TEXT,
  phone TEXT,
  share_email BOOLEAN DEFAULT FALSE,
  share_phone BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  PRIMARY KEY (id)
);

-- Chat messages
CREATE TABLE public.messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES public.profiles(id),
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Photo Gallery
CREATE TABLE public.photos (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES public.profiles(id),
  url TEXT NOT NULL,
  caption TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Voicemails
CREATE TABLE public.voicemails (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES public.profiles(id),
  url TEXT NOT NULL,
  is_public BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Enable Row Level Security
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.messages ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.photos ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.voicemails ENABLE ROW LEVEL SECURITY;

-- Public read policies
CREATE POLICY "Public profiles are viewable by everyone." ON public.profiles FOR SELECT USING (true);
CREATE POLICY "Messages are viewable by everyone." ON public.messages FOR SELECT USING (true);
CREATE POLICY "Photos are viewable by everyone." ON public.photos FOR SELECT USING (true);
CREATE POLICY "Public voicemails are viewable by everyone." ON public.voicemails FOR SELECT USING (is_public = true);

-- Users can insert their own data
CREATE POLICY "Users can insert their own messages." ON public.messages FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "Users can insert their own photos." ON public.photos FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "Users can insert their own voicemails." ON public.voicemails FOR INSERT WITH CHECK (auth.uid() = user_id);

-- Auto-delete voicemails after 30 days (optional - run separately)
-- CREATE OR REPLACE FUNCTION delete_old_voicemails()
-- RETURNS trigger AS $$
-- BEGIN
--   DELETE FROM voicemails WHERE created_at < NOW() - INTERVAL '30 days';
--   RETURN NEW;
-- END;
-- $$ LANGUAGE plpgsql;
```

### 3. Deploy to Vercel (Free)

1. **Push to GitHub:**
   ```bash
   cd echoes-of-love
   git init
   git add .
   git commit -m "Echoes of Love - Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/echoes-of-love.git
   git push -u origin main
   ```

2. **Connect to Vercel:**
   - Go to [vercel.com](https://vercel.com) and sign up (free)
   - Click **Add New Project** → Import your GitHub repository
   - Vercel will auto-detect Next.js

3. **Add Environment Variables:**
   In Vercel project settings, add:
   - `NEXT_PUBLIC_SUPABASE_URL` = your Supabase URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = your Supabase anon key

4. **Deploy!** Click **Deploy** - Vercel handles everything else.

## 🔧 Configuration

### Environment Variables

Create `.env.local` for local development:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```

### Building for Production

```bash
npm run build
```

## 📋 Features Explained

### Community Chat
- Real-time messaging powered by Supabase subscriptions
- Users can optionally share their name or remain anonymous
- "No judgment. No politics. This is a place of love." reminder displayed prominently
- Messages persist in the database for community history

### Memory Gallery
- Upload photos with captions to remember loved ones
- Grid layout with lightbox viewing
- Images stored via Supabase Storage (free tier: 1GB)

### Voicemails
- Browser-based audio recording (no server needed)
- Public voicemails visible to community
- Private voicemails only visible to creator
- Auto-delete notice: voicemails are cleared after 30 days to keep space meaningful

---

## 🔒 Security

- **Row Level Security (RLS)** ensures users can only modify their own data
- Public read for community features (messages, photos, public voicemails)
- No sensitive data exposed without explicit user consent
- Anonymous users can view but not post (optional: enable auth for posting)
